# TechNova: Back-end

Para fins de organização e manutenção do projeto, o repositório principal foi dividido em duas partes: Front-end e Back-end.

Este repositório é destinado ao desenvolvimento do Back-end da plataforma TechNova, responsável pelo processamento das informações, implementação das regras de negócio, gerenciamento dos dados e comunicação entre o banco de dados e a interface da aplicação.
